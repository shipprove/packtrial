# Decisions

## 2026-04-30: Use `shipprove` for package and action identity

Status: accepted.

PackTrial uses `@shipprove/packtrial` for the npm package and `shipprove/packtrial` for GitHub Action examples.

The org-level ShipProve concept document names `shipprove` as the canonical organization and npm scope. Some early PackTrial planning text still mentions `shipprobe`; that older name is treated as superseded for this repository.
